# README

Tables S1 and S2 from Jauréguiberry et al. (2022). 

Table_S1.csv lists partial search strings for the EBV indicators, and Table_S2.csv for different driver classes.

EBV_general.csv includes non-indicator-related partial search strings for each of the EBVs missing from Table S1 (obtained from a personal communication with Pedro Jauréguiberry).


## Reference

Pedro Jaureguiberry et al., The direct drivers of recent global anthropogenic biodiversity loss.Sci. Adv.8,eabm9982(2022).DOI:10.1126/sciadv.abm9982
