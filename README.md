# Évaluation de la biodiversité et des contributions de la nature aux populations du Québec

\[English below\]

Il s’agit d’un projet visant à évaluer l’état de la biodiversité et les contributions de la nature aux populations à travers le Québec, Canada.

Ce dépôt git contient des documents rédigés au format Quarto Markdown et utilisés pour générer un livre en ligne. La version la plus récente du livre est accessible à l’adresse suivante : <https://quebio.ca/rapport/_book>.

Vous pouvez ajouter des annotations directement sur le site web. Pour ce faire, vous aurez besoin d’un compte sur la plateforme [Hypothes.is, et faire partie du group QEB](https://hypothes.is/groups/EEQimD16/qeb).

# Assesment of Biodiversity and Nature's Contribution to People in Quebec

This is a project aiming to assess the state of biodiversity and nature's contribution to people across Québec, Canada.

This git repository contains Quarto Markdown formatted documents used to render the online book. The latest render of the e-book can be accessed at [quebio.ca/rapport/\_book](quebio.ca/rapport/_book).

You can add annotations to the website. For this, you will require a [Hypothes.is account, and being part of the QEB group](https://hypothes.is/groups/EEQimD16/qeb).
