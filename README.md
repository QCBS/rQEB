# Assesment of Biodiversity and Nature's Contribution to People in Quebec

This is a project aiming to assess the state of biodiversity and nature's contribution to people across Québec, Canada.

This git repository contains Quarto Markdown formatted documents used to render an online book.

The latest render of the book can be accessed at [quebio.ca/rapport/\_book](quebio.ca/rapport/_book). You can access the contents using the following credentials:

> username: exec

> password: ukpik

You can add annotation to the website. For this, you will require a [Hypothes.is account](https://hypothes.is/signup).
